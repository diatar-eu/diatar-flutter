# Szentírás (Bibliaversek)

A Szentírás funkció a szentiras.eu API segítségével betölti és illeszti a bibliaverseket a diasorbe.

## Előfeltétel

A `szentiras.eu` API kulcs kell. Igényléshez a szentiras.eu-n regisztrálj be, és a profil alatt igényelj API kulcsot. A kulcs beállítható a **Beállítások** → **Internet** szakaszban.

## Használat

1. Nyisd meg a **Diasor**szerkesztőt
2. Kattints a **Szentírás** ikonra
3. Add meg a hivatkozást (pl. `1Kor13,10-13`)
4. Válassz fordítást
5. Kattints a **Betöltés** gombra
