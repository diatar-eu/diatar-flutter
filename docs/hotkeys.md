# Gyorsbillentyűk

Asztali környezetben (macOS, Windows, Linux) a következő gyorsbillentyűkkel tudod a vetítést irányítani:

| Billentyű parancs | Gyorsbillentyű
|---|---|
| Előző ének | PageUp |
| Következő ének | PageDown |
| Előző versszak | ArrowUp |
| Következő versszak | ArrowDown |
| Vetítés BE/KI | Escape |
| Kiemelés előző szó | ArrowLeft |
| Kiemelés következő szó | ArrowRight |
| Előző diasor | — |
| Következő diasor | — |

Egyéb billentyűparancsok a Beállítások → Gyorsbillentyűk szakaszban testreszabhatók.

## Hol működnek a gyorsbillentyűk?

A gyorsbillentyűk attól függetlenül működnek, hogy melyik ablakon van a
fókusz, a vezérlő (fő) ablakon vagy a [vetítőablakon](projection.md). Ez
azért lehetséges, mert amikor elrejted a vezérlő ablakot, a fókusz
automatikusan a vetítőablakra kerül, és a vetítőablak a saját
gyorsbillentyű-leolvasását ugyanazra a parancsra állítja.

A vetítésen kattintva a vezérlő ablak visszatér és ismét átveszi a
billentyűzetet.
