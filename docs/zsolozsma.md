# Zsolozsma

A Zsolozsma funkció a napi liturgia diáinak automatikus generálását segíti.

## Használat

1. Nyisd meg a **Diasor**szerkesztőt
2. Kattints a **Zsolozsma** ikonra a műveletgombok között
3. Válassz dátumot és napszakot
4. A rendszer betölti a szöveget diákká bontva

## Éves ZIP szinkronizálás

Az éves liturgiai ZIP fájlokat a **Beállítások** → **Internet** szakaszban frissítheted a Zsolozsma ZIP frissítés gombbal. A letöltött fájlok automatikusan az aktuális év adatait tartalmazzák.
