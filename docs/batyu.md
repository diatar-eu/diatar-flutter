# Napi lelki batyu

A Napi lelki batyu funkció a napi olvasmányok automatikus importálását és diákká alakítását teszi lehetővé.

## Használat

1. **Diasor szerkesztése**
2. Kattints a **Napi lelki batyu** ikonra
3. Válassz dátumot
4. Állítsd be a **szavak száma diánként** értéket
6. Nyomj rá az ünnepre!
